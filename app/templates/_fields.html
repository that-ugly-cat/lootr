A datalist cannot serve one: it completes the whole box rather than the next item in it, so a list needs a real multi-select. The box underneath is how a value the vocabulary has never seen gets in — without it the widget would close a set that is open. Values already on the record are part of `options`, so nothing that was there stops being offered, or silently disappears on the next save. #} {% macro tags(name, label, value, options, allow_new=true) %} {% set chosen = value|fromjson %} {% endmacro %} {% macro field(name, value, choices, ns='f', cls='') %} {% set spec = choices.get(name) %} {% set kind = spec[0] if spec else ('textarea' if name in ('notes', 'evidence', 'hints') else 'text') %} {% endmacro %}
